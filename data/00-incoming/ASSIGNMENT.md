# Source Delivery

These files simulate a delivery from multiple business systems.

Your task is to:
1. Inspect every file without opening it blindly in Excel.
2. Determine format, size, encoding, BOM, delimiter, header and structure.
3. Preserve immutable copies in Raw.
4. Standardize the data in Bronze.
5. Clean, validate and model the data in Silver.
6. Produce business queries, KPIs and Gold datasets.
7. Record rejected rows and document each decision.

Do not assume that file extensions, column names, dates, identifiers or types are correct.
